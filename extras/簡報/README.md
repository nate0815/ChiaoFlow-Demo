# extras/簡報/ — 從大綱到可以上台的簡報

> **選用。** 跟 [Core](../../core/) 沒有依賴關係。
> **治什麼病**：簡報做出來目的不明確、資訊太雜、整份做完之後還要再修一輪。

---

## ⭐ 五個階段，順序不能顛倒

```
① 出大綱    場合卡 ＋ 逐頁大綱表          → 規劃.md 第 2、3 節
② 出內容    密度檢查（可選：出樸素 pptx 驗一次）→ 規劃.md 第 4 節
③ 出視覺    風格探索 → 選定 → 產圖         → 製作.md 第 2 節、圖表工具.md
④ 整合      帶視覺的 pptx（最終交付形態）    → 規劃.md 第 5 節
⑤ 手修      在 PowerPoint 完稿             → 你自己來
```

**為什麼視覺一定在 ④ 之前、④ 又一定在 ⑤ 之前**：

| 為什麼 | 說明 |
|---|---|
| 視覺不能比內容早 | 內容還在動的時候做視覺，每改一句話就要重跑一次，而且會誘使你用「好看」掩蓋「還沒想清楚」 |
| 整合不能比視覺早 | pptx 是**帶著選定的視覺**產出來的。先出樸素 pptx 再想視覺，等於要出兩次 |
| 手修一定最後 | 出片是**單向的**。你在 PowerPoint 動第一個字之後，重跑產生器會整份蓋掉 |

> ⛔ **不要試著「把 HTML 轉成 pptx」。** HTML 的視覺是 CSS，轉不成 PowerPoint 的形狀與文字框；
> 市面上的轉換工具產出的是**每頁一張圖片**，字選不起來、改不動。
> 正解是第 ④ 步：**讓 pptx 自己帶上那套視覺**。

## 工具

全部讀**同一份大綱**。大綱是唯一正本，沒有任何一支工具會回寫它。

| 工具 | 幹什麼 | 什麼時候用 |
|---|---|---|
| [範本/大綱.md](範本/大綱.md) | ⭐ **文案正本，也是唯一的人審點** | 階段 ① |
| [工具/density-check.py](工具/density-check.py) | 密度檢查：點數、字寬、主張是否完整句 | 階段 ② |
| [工具/outline-to-pptx.py](工具/outline-to-pptx.py) | 大綱 → **樸素** pptx（套當前範本母片） | 階段 ②（驗內容）或不需要視覺時 |
| [工具/html-deck.py](工具/html-deck.py) ＋ [工具/deck-shell.html](工具/deck-shell.html) | 大綱 → HTML 簡報（動畫、講者備忘、URL 錨點） | 階段 ③（視覺預覽）或要可分享的網址 |
| [工具/themed-pptx.py](工具/themed-pptx.py) | 大綱 → **帶視覺的可編輯 pptx** | ⭐ 階段 ④，最終交付 |

### 開始一份新簡報

```bash
mkdir 我的簡報 && cp extras/簡報/範本/大綱.md 我的簡報/

# ② 填完大綱之後跑密度檢查
python extras/簡報/工具/density-check.py 我的簡報/大綱.md

# ② 可選：出一份樸素 pptx 驗內容
python extras/簡報/工具/outline-to-pptx.py 我的簡報/大綱.md -o 我的簡報/草稿.pptx --strict

# ④ 整合成帶視覺的 pptx
python extras/簡報/工具/themed-pptx.py 我的簡報/大綱.md 我的簡報/簡報.pptx

# ③ 需要 HTML 預覽或可分享網址時
python extras/簡報/工具/html-deck.py 我的簡報/大綱.md extras/簡報/工具/deck-shell.html 我的簡報/簡報.html
```

要一個 `python-pptx`（純 Python，**不需要 LibreOffice、不需要管理員權限**）：

```bash
python -m venv .venv
.venv/Scripts/pip install python-pptx      # Windows；macOS／Linux 是 .venv/bin/pip
```

裝套件前的注意事項見 [../../setup/Python環境.md](../../setup/Python環境.md)。

## 腳本會順手幫你做的檢查

跑 `outline-to-pptx.py` 時會把這些印在畫面上：

| 標記 | 什麼情況 |
|---|---|
| ⛔ | 場合卡有欄位沒填、某頁沒有主張、某頁「服務哪一題」空白 |
| ⚠️ | 主張疑似名詞短語、內文超過點數上限或單點過寬、視覺檔案找不到、秒數加總超過場合卡的時間 |

**預設只提醒不阻擋**，加 `--strict` 才會擋下來不出檔。為什麼預設不擋，見 [規劃.md](規劃.md) 9.2。

> ⚠️ 「主張疑似名詞短語」是**啟發式判斷**（沒有句末標點又不到 12 字），會誤判。
> 它的用途是提醒你回去看 3.1 節，不是判準本身。

## 四件要知道的事

| | |
|---|---|
| **單向輸出** | 在 pptx 或 HTML 裡改的東西**不會回到大綱**。手修之後就以那個檔為正本，不要維護兩份 |
| **`（…）` 是給自己看的註記** | 大綱裡整段被全形括號包起來的內容**不會上投影片**。踩過的坑：`（封面不放條列）` 曾經真的印在封面上 |
| **範本原有的頁會被清掉** | `--template` 要的是它的**母片與版面配置**，不是它的內容 |
| **字寬用單位制** | 「每點不超過 20 字」＝ **40 單位**（中文一字兩單位、ASCII 一單位）。用字元數硬算會把放得下的網址誤判成超標 |
