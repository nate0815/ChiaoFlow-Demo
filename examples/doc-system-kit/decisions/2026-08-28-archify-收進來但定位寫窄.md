# archify 收進來，但定位寫窄成「要圖對程式碼負責時才用」

**問題是什麼**

這個 repo 的傳播瓶頸很具體：`README.md` 是三萬多字的密集文字，**最上面沒有一張圖**。
`archify`（MIT，2026-08-28 網頁顯示約 23.9k ★）主打把 repo 變成可互動的系統圖，
看起來正好治這個。

**評估過程（不是看 README，是實裝跑過）**

三條判準全過 —— 這在這個工具包擋掉的候選裡很少見：

| 判準 | 事實 |
|---|---|
| 授權能不能傳給別人 | MIT，`LICENSE` 檔本身確認 |
| 受管電腦裝不裝得起來 | 純 Node、165 個檔全是純文字**無二進位執行檔**、`doctor` 15 項全過。核心只要 **Node ≥18**，這個移植包本來就要求它 —— **沒有新的前置需求** |
| 內容不要離開你的機器 | 程式碼裡**零個 `fetch`／`XHR`**。`child_process` 六處全部無害，其中 `repository-evidence.mjs` 跑的是本機 `git -C` |

**兩個當初的假設都被實測推翻**

| 原本以為 | 實際上 |
|---|---|
| 「它讀整個 repo 自動生圖」 | **不自動生。** AI 寫型別化 JSON，它負責驗證與編譯 |
| 「這個 repo 幾乎全是 markdown，架構圖沒東西可畫」 | **有東西可畫。** 這裡的架構是三層自動化裝置加四份文件，不是執行期服務 |

**選了什麼**

收，但**定位窄**：分界寫成**輸入不同、責任也不同**。

- **archify**：圖的節點可以引用檔案路徑與行號，而工具**會對指定 commit 驗證那些引用**
- **diagram-design**：其餘全部

分界的證據是實測的：拿假路徑與超出檔案長度的行號各試一次，
**兩種都被擋下不出檔**（`does not identify a file at revision ...`、
`requests line 999, but ... has 117 lines`）。這件事 diagram-design 做不到，也不該由它做。

**四個寫進 SOP 的限制**

1. **實據功能只支援 GitHub** —— schema 正規式寫死 `^https://github\.com/...`。
   私有的 GitLab／自架 server **用不了它唯一的賣點**（已列入待決問題 5）
2. **產出的 HTML 會連 Google Fonts**，寫死在 `assets/template.html`，沒有開關。
   內容不外流，但「有人開了這個檔」會產生對外請求 → **放進 README 走手動匯 PNG**
3. **版面格線的規則沒寫在文件裡** —— 欄距不等距（實測 132／80／130／70／125），
   同一個 lane 只有 `col 0→1`、`2→3`、`4→5` 放得下兩個節點。踩到只會看到
   `nodes less than 8px apart`，看不出真正原因。實測繞了三輪、36 個錯誤才找到
4. **中文標籤吃緊** —— 一個中文字算兩單位，預設節點大約只裝得下 6 個中文字

**沒選什麼**

- **沒有拿它取代 diagram-design。** 兩者不是取代關係，`--repo-root` 與 `inspect`
  甚至只支援 architecture 一種圖，workflow 模式沒有實據功能
- **沒有裝 DeepSeek 整合。** 社群版不是官方，而且會把東西送到外部服務
- **沒有改它的 `assets/template.html` 去拔字型連結。** 那會被更新覆蓋，
  而且會破壞交付產生的 SHA-256 收據

**順帶收斂的一件事**

查的過程發現 `diagram-design` **同時裝了外掛版與 skill 版兩份**。
skill 版是 2.6（舊）、**不是 git clone 所以沒有任何更新路徑**；
外掛版 2.6.6 有自動更新，SOP 寫的也是它。**移除 skill 版，留外掛版。**
品牌 profile 依設計存在安裝目錄外，刪除不影響。
