# Obsidian 降級為可選閱讀器，不是體系的地基

**選了什麼**

三層架構。L0（純檔案慣例）是必要的、只要 git ＋ grep 就成立；
L1（Obsidian 內建的反向連結、關係圖、改名自動更新）是選用的閱讀增益；
L2（Dataview 等外掛）只做人看的視圖，**永不當正本**。

**沒選什麼、為什麼不選**

把 Obsidian 當地基。那樣一來移植包的安裝從「複製四個檔、10 分鐘」變成
「裝軟體 ＋ 裝外掛 ＋ 學查詢語法 ＋ 半天」—— 而這套東西的賣點就是帶得走。

而且 Obsidian 的建置 SOP 自己就寫了：**最常見的坑是花三週調外掛而不是寫文件。**

**如果錯了會怎樣**

如果 L1 的反向連結實際上不夠用、非得靠 Dataview 才查得動，那 L2 的
「永不當正本」限制就過度了，得重新設計 frontmatter 讓它撐得起查詢。

**代價**

L1 的價值要真的拿到，得有人**實際寫連結**。反向連結不會腐爛，但它也不會自己長出來。
