**決策**

**踩坑**

  把繼承來的 `top`／`height` 清掉。**腳本照樣印「出了 12 頁」**

**量到的事實（不是感覺）**

| 量的東西 | 數字 |
|---|---|
| 出片腳本的版面 bug 影響範圍 | 12/12 頁全中，`--strict` 也過。**只有不給 `--template` 時才會中** |
| archify 檔案組成 | 165 個檔，117 個 `.mjs`、31 個 `.json`、11 個 `.md`、6 個 `.html`，**0 個二進位** |

| diagram-design 重複安裝 | skill 版 2.6（無更新路徑）vs 外掛版 2.6.6（有自動更新） |

**這一輪最值得記的一件事**

三個問題都不是靠讀文件發現的，是**拿流程實跑一遍逼出來的**：

1. 出片腳本的 bug —— 要把 pptx 用 PowerPoint 打開才看得到
2. SOP 兩條規則的適用範圍 —— 要真的做出一份「內容匱乏」的成品才知道
3. archify 的欄距規則 —— 要撞到 36 個錯誤再去量座標才量得出來

跟 [../DEVLOG.md](../DEVLOG.md) §3 那句「規則寫得再完整都會漏」是同一件事的另一面：
**文件寫得再完整，也要有人真的跑一遍才知道哪裡不對。**

**決策**

- [簡報流程定案為五階段](../decisions/2026-08-28-簡報流程定案為五階段.md)
  —— **部分修訂** 8/27 那則：三道閘門仍然生效，改的是出片順序

**量到的事實（不是感覺）**

| 量的東西 | 數字 |
|---|---|
| HTML → pptx 轉換 | **不通**。HTML 的視覺是 CSS，轉換工具產出的是每頁一張圖片，字改不動 |
| 視覺用的字型 | Geist／Instrument Serif／Geist Mono **本機都沒裝**；改用 Noto Sans TC ＋ Cascadia Code |
| 主題化 pptx | 25 頁、572 KB、每頁一張共用底圖、7 頁內容圖、幾何重疊 **0 處** |
| 產圖管線 | Edge 151 無頭截圖 ＋ Pillow 去邊，**零安裝**取代 Playwright |
| 連結檢查 | 兩次資料夾重整，各自從「壞掉 18 條 / 十幾條」修回 **0 條** |

**這一輪最值得記的一件事**

我一度想把圖的畫布加寬，讓節點文字在投影片上變大 —— **方向完全錯了**。
archify 的 `composition/desktop-readability` 直接擋下來並說明原因：
整張圖還是要縮進同一個框，加寬只會讓文字**相對變小**。

> ⭐ **要讓圖上的字變大，唯一的槓桿是「減少節點」，不是「放大畫布」。**

這是這一輪唯一一次「工具比我對」的地方，而且它是**擋下來並說明理由**，不是默默照做。
