# 拆檔之後每次收工都被擋，訊息說 DEVLOG 沒動 —— 但明明寫了

**現象**

DEVLOG 拆檔之後，回填明明寫了 `doc/devlog/2026-08-26.md`，
收工還是被擋，reason 說「`doc/DEVLOG.md` 沒動」。而且**每一次**都擋。

**原因**

`doc-sync-check.mjs` 的兩處比對邏輯不對稱：

```js
// TRIGGERS：支援目錄前綴
const hit = changed.filter((f) => TRIGGERS.some((t) => (t.endsWith('/') ? f.startsWith(t) : f === t)))

// GATE：嚴格相等
if (changed.includes(GATE)) bail()
```

`GATE = 'doc/DEVLOG.md'`，用 `Array.includes` 比對，只認完全相同的字串。
拆檔後動的是 `doc/devlog/2026-08-26.md`，`doc/DEVLOG.md` 整輪都不動 → 閘門恆擋。

**這不是拆檔之前就存在的 bug，是拆檔的前置改動。**

**解法**

`GATE` 改成陣列，比對邏輯抽出來與 TRIGGERS 共用：

```js
const GATE = ['doc/DEVLOG.md', 'doc/devlog/', 'doc/decisions/', 'doc/gotchas/']

const matches = (f, list) => list.some((t) => (t.endsWith('/') ? f.startsWith(t) : f === t))
const hit = changed.filter((f) => matches(f, TRIGGERS))
if (hit.length === 0) bail()
if (changed.some((f) => matches(f, GATE))) bail()
```

已列入 [../TECH.md](../TECH.md)「不變式」第 5 條。
