# 出的 pptx 標題與內文疊在頁面最上緣，而腳本說「出了 12 頁」

**現象**

`outline-to-pptx.py` 跑完印出「出了 12 頁 → 簡報.pptx」，`--strict` 也過了。
用 PowerPoint 開起來，**每一頁的標題與內文都疊在頁面最上緣**，標題被自動放大到滿版。

沒有任何錯誤訊息。腳本、python-pptx、PowerPoint 三邊都不覺得有問題。

**原因**

`build()` 把內建的 4:3 範本撐成 16:9 時，只縮放了 `left` 與 `width`：

```python
if ratio != 1.0:
    for ph in slide.placeholders:
        ph.left, ph.width = int(ph.left * ratio), int(ph.width * ratio)
```

python-pptx 的 placeholder 在**沒有明確 `<a:xfrm>` 時，位置與尺寸是從版面配置繼承的**。
一旦寫入 `left`，它會就地生出一個明確的 `<a:xfrm>`，而那個元素的
`off/@y` 與 `ext/@cy` **預設是 0** —— 繼承來的 `top` 與 `height` 就這樣被清掉。

實測產出檔：兩個 placeholder 都是 `top=0.00, height=0.00`。

讀取順序也不能顛倒：寫完 `left` 之後再讀 `ph.top`，拿到的已經是 0。

**只有不給 `--template` 時才會中。** 給了既有範本 `ratio == 1.0`，這段整個跳過 ——
所以「用範本測沒事、不用範本就壞」。

**解法**

四個值一次讀完再寫，而且四個都要寫：

```python
left, top, width, height = ph.left, ph.top, ph.width, ph.height
ph.left, ph.top = int(left * ratio), top
ph.width, ph.height = int(width * ratio), height
```

修完實測 12/12 頁不再重疊（標題 top 0.30 高 1.25 → 底邊 1.55，內文從 1.75 開始）。

**這是「壞掉但不會報錯」的典型**，跟 [../DEVLOG.md](../DEVLOG.md) §3 收的
Dataview 與 wikilink 是同一個家族 —— 差別只在這次壞的是產出物，不是文件引用。
