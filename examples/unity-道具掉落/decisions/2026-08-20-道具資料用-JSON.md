# 道具資料用 JSON

**選了什麼**

道具定義（名稱、稀有度、堆疊上限、掉落權重）存成 `Assets/StreamingAssets/items.json`，
執行時反序列化成 `ItemDef` 物件。

**沒選什麼、為什麼不選**

- ScriptableObject —— 當時判斷「一個道具一個資產檔」在道具數量上百之後會讓 Project
  視窗很難找，而且 SO 不好做批次比對（例如「所有稀有度 3 的道具」）。

**如果錯了會怎樣**

掉落表、背包、UI 三處都是吃 `ItemDef` 介面，換掉資料來源的話這三處要跟著改。
