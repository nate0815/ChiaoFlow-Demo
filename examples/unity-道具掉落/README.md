# 道具掉落與背包

**敵人死亡時依掉落表產生道具、玩家走過去自動拾取進背包的 Unity 模組。**

做來驗證兩件事：自動拾取的手感夠不夠順、20 格背包夠不夠用。
掉落表是 ScriptableObject，企劃可以在 Inspector 直接調參數，不必找程式。
**目前是 prototype**，只在測試場景裡跑過。

---

## 怎麼跑起來

```
1. Unity 2022.3 LTS 開啟本專案（第一次開會編 shader，約 3 分鐘）
2. 開 Assets/Scenes/LootTest.unity
3. 按 Play
```

打死場上的測試假人，看到道具掉出來、走過去自動消失、右上角格數 +1，就是跑起來了。

**前置需求**：Unity 2022.3 LTS。沒有其他外部相依，不必先裝套件。
